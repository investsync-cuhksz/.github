# InvestSync Technology

InvestSync is the student investment organisation of The Chinese University of Hong Kong, Shenzhen. The tech team builds the tools the club runs on.

## Projects

| # | Project | What it is | Team |
|---|---------|------------|------|
| 1 | [Virtual Fund](https://github.com/investsync-cuhksz/virtual-fund) | A paper portfolio the club runs, with every decision recorded and measured against the market | Kellen Joudan, Christian Angelo V, Karel Hutajulu |
| 2 | [Websites](https://github.com/investsync-cuhksz/websites) | A new club website: a public side for visitors and a members-only side for running the club | Jason Sukiman, Celine Clarissa, Karel Hutajulu |
| 3 | [Research Tools](https://github.com/investsync-cuhksz/research-tools) | A tool that turns any ticker into a one-page company summary for analysts | Birlik Yessen, Karel Hutajulu |

## How we work

- Write a short PRD, sketch the design, check with the coordinator, then build and test in small steps
- Work on a branch and open a pull request; your partner reviews before anything is merged into `main`
- Keep each repo's README up to date, with screenshots or diagrams where they help
- Keep passwords, API keys and `.env` files out of Git
